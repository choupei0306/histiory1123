1. 商業資本主義 vs 工業資本主義演變表

第 2 章
階段 時間與背景 核心制度與特色 代表案例與影響
商業資本主義 16～18世紀（中古後期商業活絡、大航海時代、商業革命） 銀行業與信用制度、合股公司分攤風險、交易所與股票市場、政府頒特許狀予「特許公司」享專賣獨占權 1602 阿姆斯特丹證券交易所、英國東印度公司、荷蘭聯合東印度公司
工業資本主義 18世紀中～19世紀中（工業革命加速發展） 資本投入工業擴大生產；政府頒布「有限責任法」防範泡沫化並保障投資人；科學與工業結合、重視研發與職教 證券經紀公司興起、刺激產業合併（帶來新工作機會，也造成失業與貧富不均）

2. 社會主義三大學派 ＆ 英國國會改革年表

第 2 章
學派 / 法案 時間 代表人物 / 受惠對象 核心主張與改革內容
烏托邦社會主義 19世紀前期 聖西門 主張建立「公社」、「合作社」，經濟互助以達均富
馬克思社會主義 19世紀中期 馬克思 主張暴力革命奪權，強調唯物辯證法、剩餘價值、階級鬥爭
費邊社會主義 19世紀後期 蕭伯納 主張漸進溫和改革，提倡組織工黨、透過國會立法改善勞工待遇
英國國會改革 1832年 中產階級受惠 廢除「衰敗市鎮」席次，重配給新興工業城市（憲章運動訴求之一）
英國國會改革 1867 / 1884年 1867 工人 / 1884 農民 兩度放寬選舉財產門檻與名額，擴大男性普選基礎
英國婦女參政 1918 / 1928年 女性選民 1918 部分婦女獲選舉權（有年齡與財產限制）；1928 降齡並取消財產限制

3. 伊斯蘭早期政權演變 ＆ 16世紀三大帝國比較

第 3 章
政權 / 帝國 時間與首都 政治與宗教特色 重要成就與衰亡
正統哈里發 632–661 烏瑪「推舉制」產生四位哈里發；阿拉伯文成官方語 征服埃及、敘利亞、兩河、波斯；後期因繼承爆發內戰
奧瑪雅王朝 661–750｜大馬士革 哈里發改「世襲制」；實行阿拉伯中心政策（特權） 征服北非、西班牙、中亞；遭反對者與波斯人推翻
阿拔斯王朝 750–1258｜巴格達 重用波斯官僚、重心東移；10世紀後面臨後奧瑪雅與法提馬挑戰 8–10世紀「黃金時代」（智慧宮、百年翻譯）；1258 亡於蒙古
鄂圖曼帝國 13世紀末起｜伊斯坦堡 奧斯曼建立、橫跨歐亞非；「新軍」制度（非穆斯林改信受訓） 1453 滅拜占庭；1683 維也納之戰敗北由攻轉守、財政失衡
薩法維帝國 16世紀初｜伊斯法罕 伊朗一帶；以「什葉派」為國教區別鄂圖曼 阿拔斯時期鼎盛、波斯細密畫；邊緣化遜尼派導致內亂分裂
蒙兀兒帝國 16世紀初｜德里 蒙古後代建於北印度；阿克巴採宗教寬容、貿易發達 細密畫高度發展；奧朗則布改獨尊伊斯蘭激化對立而衰

4. 近代伊斯蘭改革、二戰後三路線 ＆ 女性服飾對照

第 3 章
分類 / 名稱 代表人物 / 國家 / 地區 核心特色與考點
19世紀泛伊斯蘭 阿富汗尼 / 阿布杜 阿富汗尼倡團結全球穆斯林擁共同哈里發＋學西方科技；阿布杜倡調和傳統與現代（埃及愛資哈爾大學傳播）
二戰後：保守派 沙烏地阿拉伯、塔利班阿富汗 根據對伊斯蘭教法的理解與詮釋來治理國家
二戰後：世俗派 土耳其 以西方現代化標準改造穆斯林社會，匹配科學與世俗行為
二戰後：折衷派 穆斯林兄弟會 學習特定西方科技、調和傳統信仰與科學，達成「現代化而非西方化」
服飾：布卡 / 尼卡伯 阿富汗 / 沙烏地阿拉伯 布卡（Burqa）覆蓋率最高，眼部僅留網狀窗口；尼卡伯（Niqab）遮臉只露雙眼（2010法國禁公共場所遮臉面紗）
服飾：喜瑪爾 / 恰多爾 / 喜加伯 伊朗、北非 / 全球最常見 喜瑪爾（遮頭頸肩至腰露臉）、恰多爾（全身罩袍露臉）、喜加伯（Hijab，最常見頭巾，樣式多元）

5. 葡西荷英擴張比較 ＆ 哥倫布大交換 / 三角貿易

第 4 章
國家 / 主題 核心據點與年代 經營策略與影響
葡萄牙 1488好望角、1498印度、麻六甲、澳門、長崎 最先建帝國，以港口強制商船繳關稅掌控航線，打開中日貿易
西班牙 1492美洲、1521阿茲提克、1533印加 深入內陸直接統治、開採白銀（引發歐洲物價革命），美洲古文明瓦解
荷蘭 1602 VOC、巴達維亞（爪哇）、1624臺灣 壟斷香料群島（丁香、肉豆蔻）；以臺灣為中日東南亞轉口中心
英國 1600東印度公司、印度、北美十三殖民地 1651起頒「航海法」引發荷英海上戰爭，擊敗荷蘭成新殖民霸權
哥倫布大交換 1500年後 新大陸 ↔ 舊大陸 新→舊：馬鈴薯、番薯（助人口成長）、玉米、番茄、辣椒、菸草、可可豆、火雞、南瓜、鳳梨。
舊→新：甘蔗、咖啡、牛羊馬豬、小麥、香蕉、葡萄、疾病（原住民浩劫）。
三角貿易 16–19世紀（總計約1,252萬奴隸） 歐洲（蘭姆酒、槍砲、布匹）→ 西非奴隸海岸（黑奴，18世紀最高約649萬）→ 美洲（熱帶作物、菸草、金銀）→ 歐洲。

6. 19世紀列強在非洲、亞洲、太平洋拓殖 ＆ 維持獨立國家總整

第 4 章
區域 列強拓殖重點 維持獨立國家與關鍵原因（必考！）
非洲大獵 1850奎寧治瘧疾＋李文斯頓著作；1884俾斯麥柏林會議；英縱向、法橫向貫穿；比利時利奧波德二世剛果「血橡膠」；早期特許公司→20世紀初政府直統 衣索比亞（擊敗義大利）、賴比瑞亞（美國扶持）
印度與東南亞 英1763獨霸印度、1858直接統治（鐵路電報不對稱貿易、禁娑提）；英1824新加坡、馬來亞（橡膠錫）、緬甸（柚木紅寶石）；法中南半島（越寮柬） 暹羅（泰國）：處英法緩衝區＋國王拉瑪五世（朱拉隆功）中央集權與西化改革
中亞 俄羅斯主要動機為「領土與暖水港」（市場原料次要），19世紀下半葉併入大部分中亞 直至 1991年蘇聯解體 後中亞各國才紛紛獨立
太平洋 澳紐定居殖民地；19世紀初蒸汽船補給站（法大溪地、英斐濟）；1898夏威夷王國併入美國 東加王國（尋求英國保護維持獨立）
